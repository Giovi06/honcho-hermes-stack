# Giovanni Knowledge Vault

This vault is the curated, human-readable companion to [[04 Operations/Honcho and Hermes Memory]].

- **Honcho** stores conversational memory, semantic recall and user-model conclusions.
- **This vault** stores durable project documentation: scope, architecture, decisions, observations, runbooks and status.
