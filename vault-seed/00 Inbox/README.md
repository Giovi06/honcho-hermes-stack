# Inbox

Temporary capture area for ideas, unclassified discoveries, legacy/debt findings, open questions and material that has not yet earned a permanent destination.

Use [[_templates/Inbox Item]] when a finding needs context and a recorded triage outcome. Review regularly and choose an explicit disposition: move useful content to a project, area or reference note; put codebase-specific material in the relevant repository's `docs/`; promote accepted work to the approved team tracker; or archive/discard it.

Do not use this inbox as a permanent backlog, an agent transcript store, or a copy of company repository documentation.
