# How-to guides

How-to guides help a developer or operator achieve a specific outcome. Use a short verb-led filename and copy [_template.md](_template.md) as the starting point.

Keep a guide procedural and focused. Put factual lookup material in [reference](../reference/README.md), design rationale in [architecture](../architecture/README.md), and production recovery procedures in [operations](../operations/README.md).
